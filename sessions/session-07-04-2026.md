## Topics covered:
### What is Vector Search
Semantic (vector) search is a retrieval method that looks for the meaning behind a query rather than just matching exact keywords. Using machine learning models, data is converted into mathematical representations called "vector embeddings" and plotted in a high-dimensional space. When you search, the system calculates the distance between your query's vector and the database vectors, returning results that are conceptually similar even if they share zero identical words.

### Use Cases
Because it understands context, vector search is the backbone of Retrieval-Augmented Generation (RAG), which securely feeds relevant documents to AI chatbots. It is also heavily used in e-commerce for intuitive product discovery (e.g., matching "autumn jacket" with "fall windbreaker"), in customer support for routing tickets based on problem descriptions, and in multimodal systems where users can search for un-tagged images or audio using text descriptions.

### Advantages and Disadvantages
The biggest advantage of vector search is its ability to handle typos, synonyms, and conversational language, finding relevant context where a strict keyword search would turn up blank. However, its main disadvantage is a lack of strict precision; unlike traditional queries, vector search struggles to filter by exact numerical values, specific database IDs, or strict boolean logic (like "price < 50"), which is why many modern databases use a hybrid approach combining both semantic and exact keyword search.
